# VÖKA — Moda Streetwear Importada

> **Menos peças, mais intenção.**

Marca de streetwear minimalista e unissex baseada em Maringá, PR. Importação direta e **curada** de vestuário de algodão pesado (fibra longa, 300–320g) para distribuição no Brasil e América Latina. Importar, aqui, é escolher: gramatura e fibra que o varejo comum não entrega.

## Identidade da marca

| Item | Valor |
|------|-------|
| Nome | VÖKA |
| Tagline (mercado/SEO) | Moda Streetwear Importada |
| Voz de marca (editorial) | Menos peças, mais intenção |
| Símbolo | **O Par** — dois pontos (um cheio, um vazado), do Ö do nome |
| Tipografia display | Outfit (Google Fonts, weight 200–300) |
| Tipografia body | DM Sans (Google Fonts, weight 300–400) |
| Tipografia detalhe | DM Mono (preços, códigos, labels) |
| Preto | #0A0A0A |
| Charcoal (primária) | #2D2926 |
| Off-white (fundo) | #F5F0EB |
| Cream | #E8E0D6 · Sand #C4B5A2 · Stone #8C8579 · Warm gray #B5ADA3 |
| Público | Unissex, 18–35, streetwear minimalista |

> Paleta **monocromática quente, sem cor de acento**. A marca aparece sempre em uma única cor da escala: charcoal sobre claro, ou off-white sobre escuro. Sem gradientes.
